# Cognitive Drift Institute

README v2 - June 2026

The Cognitive Drift Institute is the dedicated public repository for the cognitive branch of the Reality Drift framework.

## Overview

Cognitive Drift describes the gradual shift in how human cognition operates under modern informational conditions. It emerges when internal models of reality become shaped more by mediated environments than by direct experience.

Human cognition evolved through repeated feedback and relatively stable patterns of meaning. These conditions kept perception and judgment closely tied to the environments they were tracking. Modern informational environments operate differently. Information now passes through layers of filtering and reinterpretation before it reaches the mind.

As those layers accumulate, cognition increasingly works through representations rather than direct contact with the world. Information is processed in shorter cycles, and interpretations are revised more often before they fully settle.

## Core Concepts

The Cognitive Drift framework is organized around a set of related concepts that describe how cognition changes under modern informational conditions.

These include:

- Cognitive Drift

- Filter Fatigue

- Co-Cognition

- Cognitive Hygiene

- Recursive Compression

- Attention Fragmentation

- Judgment Failure

- Meaning Exhaustion

- Distributed Cognition

Together they describe how cognition remains operational while gradually reorganizing the ways attention, meaning, and judgment stabilize.

---

## Scope and Application

Cognitive Drift is a descriptive framework for analyzing how modern informational environments reshape cognition across digital media, AI-human interaction, distributed systems, and institutional life. It is not a clinical model, diagnostic system, or therapeutic framework.
