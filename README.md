# Cognitive Drift Project v2

The Cognitive Drift Project is the primary public repository for the Cognitive Drift framework by A. Jacobs.

Cognitive Drift describes how human cognition gradually reorganizes under conditions of continual mediation, information overload, optimization pressure, and artificial intelligence. As more experience passes through interfaces, algorithms, and compressed representations, attention, judgment, and meaning become increasingly shaped by representations rather than direct experience.

## Core Concepts

The Cognitive Drift framework examines how cognition adapts under modern informational conditions through concepts including:

- Cognitive Drift
- Filter Fatigue
- Co-Cognition
- Cognitive Hygiene
- Recursive Compression
- Attention Fragmentation
- Distributed Cognition
- Meaning Exhaustion
- Judgment Under Mediation

---

## Scope

The Cognitive Drift framework provides a descriptive model for understanding how cognition changes under sustained interaction with digital media, algorithmic systems, and AI-assisted environments. It is intended as a framework for cognitive and informational analysis rather than a clinical or diagnostic model.
