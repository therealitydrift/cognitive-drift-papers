# Media Assets

## Visual and Supporting Media for the Cognitive Drift Institute

### Overview

This directory contains visual assets and supporting media produced by the Cognitive Drift Institute.

These materials accompany canonical papers, essays, diagnostics, and educational materials, helping translate abstract concepts into visual form.

---

## Structure

**[Article Visuals](https://github.com/therealitydrift/cognitive-drift-institute/tree/main/02_Media_Assets/Article_Visuals)**  
Visual assets created to accompany essays, articles, and explanatory materials across the Cognitive Drift framework.

---

## Role Within the Framework

Media assets support the interpretive and educational layers of the Cognitive Drift Institute. They provide visual scaffolding for complex ideas, improve conceptual accessibility, and preserve key diagrams and illustrations used throughout the archive.

---

## Intended Use

These materials may be used for:

- Visual reference  
- Educational support  
- Article illustration  
- Conceptual explanation  
- Framework distribution
