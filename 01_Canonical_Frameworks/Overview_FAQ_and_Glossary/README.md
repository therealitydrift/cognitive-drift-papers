## Foundational Orientation Documents for the Cognitive Drift Institute

### Overview

This directory contains the primary overview and FAQ documents for the Cognitive Drift Institute.

These materials introduce the central concepts, structural logic, and interpretive boundaries of Cognitive Drift and Co-Cognition, serving as the main entry point into the broader framework.

They establish the conceptual foundation for understanding how cognition changes under conditions of recursive information, symbolic mediation, and AI-assisted reasoning.
