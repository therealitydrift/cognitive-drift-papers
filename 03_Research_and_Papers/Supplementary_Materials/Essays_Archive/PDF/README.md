# PDF Versions

## Archived PDF Essay Editions

### Overview

This directory contains PDF versions of early long-form essays produced by the Cognitive Drift Institute.

These documents are preserved as fixed-format archival editions of exploratory essays related to cognitive drift, recursive compression, co-cognition, symbolic environments, and AI-mediated cognition.

The materials in this folder represent earlier interpretive and conceptual work rather than the current canonical framework structure.

---

## Contents

This directory includes PDF essays related to topics such as:

- cognitive porousness and co-cognition  
- synthetic flow and mirror effects  
- recursive compression and consciousness models  
- identity drift and symbolic environments  
- recursive thinking and cognitive structure  
- AI-mediated cognition and representational loops  

Each document is preserved as a standalone PDF edition.
